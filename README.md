# merch-dash

Персональный дашборд мерчандайзера проекта KT&G.

Страница: https://sibanalitycs-blip.github.io/merch-dash/

В репозитории только собранный сайт: `index.html` (одним файлом, без внешних
библиотек) и `data.json` — блоки показателей по маршрутам, каждый зашифрован
персональным кодом своего маршрута (PBKDF2-HMAC-SHA256, AES-GCM). Открытых
персональных данных в репозитории нет. Расшифровка происходит в браузере.

Исходные данные, движок сборки и реестр кодов доступа хранятся отдельно
и сюда не выкладываются.
